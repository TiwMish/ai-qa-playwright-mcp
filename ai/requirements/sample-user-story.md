# Sample user story (input for the AI test-design workflow)

**US-TODO-01 — Manage a personal task list**

> As a busy professional, I want to keep a simple list of tasks in my
> browser so that I can track what I still need to do.

**Acceptance criteria**

1. I can add a task by typing it and pressing Enter.
2. The list shows how many tasks are still left to do.
3. I can mark a task as completed; completed tasks are visually distinct.
4. I can filter the list to show All, Active, or Completed tasks.
5. I can clear all completed tasks in one action.
6. My tasks are still there if I reload the page.

**Out of scope:** accounts, sync between devices, due dates.
